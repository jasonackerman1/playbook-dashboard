Data & calculation rules

Data updates the same way as every other dashboard here: drop the latest Course Completions export (the ItemStatusWithCourseLength report) into lms-engagement-data/ in the repo and push. Any months in the new file replace the same months already loaded, so it’s fine if a file overlaps earlier ones. Add a LinkedIn Learning export the same way to use actual hours viewed instead of the default course length.

What’s loaded

    Calculation rules

    Course length in the export is in hours. Only employee records (domain EMP_BUS) with a completed status are counted; dealers and certifications are left out. Learners whose user ID starts with C (Canada) count as BCA. These two settings are saved in your own browser only — they change how this page displays the loaded data, not the data itself.

    Course rules

    Mark which courses count as compliance, and which department each instructor-led course belongs to. Changes apply straight away and are saved in your own browser.
